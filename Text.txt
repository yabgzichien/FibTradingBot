BTC bot (Hyperliquid)

compute_latest_signal just checks structure and trend, then always returns a signal when trend and swings are valid:
Long: entry = sh - swing_range * FIB_LEVEL, sl = last_swing_low, tp = last_swing_high
place_entry_with_tp_sl then places a limit order at entry and waits to be filled, regardless of what the latest candle did.
There is no requirement that the last candle’s high/low “touched” the fib level.
XAUUSD bot (MT5)

In analyze_and_trade, after computing the same entry_level, it adds extra conditions on the last closed M15 candle:
Long only if:
candle_low <= entry_level and candle_open > entry_level
Short only if:
candle_high >= entry_level and candle_open < entry_level
It then uses the current bid/ask (with slippage and broker-stop checks) and sends a market order only when that specific candle pattern occurs.
If the pattern is not met, it logs “Uptrend active. No long trigger on last closed candle…” and does nothing (no resting order).
